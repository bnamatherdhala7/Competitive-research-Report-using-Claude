**Audience**: Growth PM · Acquisition team

**Analyzed**: Midjourney · OpenAI · Canva AI · Stable Diffusion · Microsoft Designer · Ideogram · Getty GenAI

---

## TL;DR

Firefly has the best enterprise story in AI image generation — IP indemnification that no competitor offers — but it has zero PLG acquisition motion and ranks for almost none of the high-volume queries users type when choosing an AI image tool. The two things to fix this quarter: (1) remove the login gate so free tier users can generate without an account, which directly improves dwell time and organic rankings; (2) launch three landing pages targeting the "commercially safe AI" keyword cluster that Midjourney's lawsuit exposure has left completely unclaimed. These two moves cost nothing and can shift Firefly from invisible to ranking top-3 within 90 days.

## Why Customers Choose Firefly (Win Criteria)
1. **IP indemnification** — enterprise legal requires it; Midjourney's lawsuit stack makes it a procurement blocker
2. **CC integration** — Generative Fill inside Photoshop; no app switching
3. **Custom Models** — only product that trains on a brand's own image library
4. **Commercially safe training data** — no scraped web content; reduces legal exposure even below the indemnification level
5. **Firefly AI Assistant** — agentic orchestration across all CC apps (only product in category with this)

## Why Customers Leave or Don't Try (Churn Triggers)
1. Credit system is opaque and punitive — users burn credits without understanding why
2. Output quality gap vs. Midjourney V8 — perceived as "too generic" for creative professionals
3. Login gate blocks free evaluation — Ideogram and Canva let you start immediately
4. Price vs. standalone tools — $59.99/mo CC bundle vs. $10 Midjourney or $15 Canva
5. No viral loop — processed images carry no Firefly attribution and generate zero inbound

## PLG Acquisition Motion — Now / 3 Months / 6 Months

### Now (0–30 days) — Remove friction, plant the flag

**1. Remove login gate on first generation**
- Competitors: Ideogram (10/day free, no account), Canva (5/month free), Microsoft Designer (15 boosts/day free)
- Change: allow first 5 generations per session without account creation; gate on download or 6th generation
- Add "No account needed" subtext under every free tool tile
- Why it matters: login gate is the single biggest driver of high bounce rate → depressed rankings → low organic acquisition. Smallpdf's 2023 UX case study showed +40% dwell time and +2 ranking positions within 60 days of removing their gate.
- Metric: free tier activation rate, tool page dwell time, bounce rate change

**2. Add "Commercially Safe AI" to every Firefly page headline**
- Zero engineering, CMS change only
- H1 on all Firefly pages: add "Commercially safe · IP indemnified · CC integrated"
- This is an exact match for the highest-intent commercial buyer queries that currently have zero competition
- Metric: impressions + CTR on commercial safety queries in Search Console

**3. Credit system: add real-time transparency**
- Show "You have ~40 standard images remaining this month" in-product at all times
- Move Standard plan to unlimited standard generations (credit-based only for premium/4K) — matches Midjourney Standard's unlimited relax mode
- Metric: monthly active generation rate among paid subscribers, churn rate change

### 3 Months — Build self-sustaining loops

**Loop 1: Custom Model sharing loop (counter: Canva template flywheel)**
- Mechanic: brand creates a Custom Model → shares access with agency/freelancers → each recipient needs a Firefly account to generate from that model → natural B2B top-of-funnel
- Build: Custom Model sharing with permissions, "request access" flow that converts viewers to trial signups, team onboarding prompt after first share
- Counter to: Canva's template sharing (reportedly 20–30% of new signups come from shared designs)
- Metric: Custom Model share → new account activation rate (target: 15%+)

**Loop 2: Output attribution badge (counter: Midjourney's Discord showcase)**
- Mechanic: opt-out "Created with Adobe Firefly" badge on free tier exports; opt-in for paid. Badge links to firefly.adobe.com/try. Every shared image → passive Firefly ad
- Build: badge injection at export (image metadata + optional visible footer), attribution tracking, Behance integration as showcase destination
- Counter to: Midjourney's Discord community and Canva's "Made with Canva" badge (the #1 driver of Canva's viral growth)
- Metric: attribution link click → signup conversion (target: 3–5%)

**Loop 3: In-app CC seat activation (counter: M365/Canva default)**
- Mechanic: existing CC subscribers who've never opened Firefly get an in-app prompt in Photoshop when they attempt any task where Generative Fill would help — "Try this with Firefly AI — included in your plan"
- Build: intent-based trigger in Photoshop (detected: user is manually masking, or pasting from stock) → inline Firefly invite
- Counter to: Microsoft Designer's passive availability in M365 driving daily usage without acquisition spend
- Metric: CC subscriber Firefly activation rate (from current ~40% to 70%+ target)

**Loop 4: Integration-led discovery (counter: Microsoft's M365 embedding)**
- Mechanic: Firefly appears in Google Slides, Notion, and Figma as an AI image option — meeting users in the tools they already live in
- Build: Google Workspace add-on, Figma plugin (Firefly generation inside design canvas), Notion integration
- Counter to: Microsoft Designer's Windows 11 + Teams + Office embedding
- Metric: new signups attributed to integrations

### 6 Months — Compounding moats

**Moat 1: Custom Models marketplace**
- Brand teams publish style models publicly; freelancers license them via Adobe Stock royalty model; creators earn credits; platform accumulates a style library no competitor can replicate
- Why it compounds: each new model makes the platform more valuable; once your brand's model is in the marketplace, the switching cost is structural
- Build: creator profiles, model publish + discovery, quality curation, credit/royalty system

**Moat 2: Firefly AI Assistant as creative OS**
- The April 2026 agentic launch is the only multi-app orchestration layer in any AI creative tool. Canva, Midjourney, Ideogram, and Designer are all single-app tools
- Moat logic: to compete with Firefly AI Assistant, a competitor needs to own Photoshop + Illustrator + Premiere + Lightroom + Express simultaneously. No one can build that in 6 months.
- Build: deepen AI Assistant's Photoshop and Premiere integrations, add shared session history for team workflows, launch "campaign in one prompt" showcase

**Moat 3: Firefly API + enterprise DAM ecosystem**
- Every enterprise API integration is a distribution channel at zero marginal CAC
- Build: Firefly Services API with IP indemnification embedded, connectors for AEM, Workfront, Bynder, Widen; partner program for ISVs
- Why it compounds: enterprise DAM procurement locks in for 3–5 years; first-mover in commercially-safe generative API within each DAM is permanent distribution
